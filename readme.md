# VideoStatsAggregator

VideoStatsAggregator — это сервис для сбора и агрегации статистики просмотров видео с различных платформ. Он предоставляет удобный интерфейс через Telegram-бота для владельцев контента и аналитиков, чтобы следить за динамикой просмотров без необходимости вручную заходить на каждую платформу.

## Описание проекта

VideoStatsAggregator позволяет получать актуальную статистику по видео с платформ. Система собирает данные о просмотрах и отображает статистику через Telegram-бота.

Основной функционал включает:

- Получение ссылок на видео.
- Определение платформы и сохранение ссылки в базе данных.
- Получение и отображение статистики по просмотрам.
- Поддержка видео платформ. На данный момент поддерживается только YouTube. Предполагается поддержка других платформ, таких как: Дзен, VK Видео, RuTube
- Возможность обновления статистики.
- Использование PostgreSQL для хранения данных.

## Технологии и инструменты

- Java 17.0.9+: Основной язык разработки.
- PostgreSQL 17: База данных для хранения статистики.
- Hibernate 7.3 : ORM для базы данных
- Docker: Для развертывания приложения.
- Telegram Bot API: Для взаимодействия с пользователем через Telegram.
- YouTube Data API V3: Для получения статистики с YouTube.
- Gradle: для сборки проекта

## Установка и запуск

### Клонирование репозитория

Для начала клонируйте репозиторий на вашу машину:
```
git clone git@github.com:grvinokursky/VideoStatsAggregator.git
cd VideoStatsAggregator
```

### Настройка конфигурационного файла
- `POSTGRES_DB` - имя базы данных
- `POSTGRES_USER` - имя пользователя БД
- `POSTGRES_PASSWORD` - пароль пользователя БД
- `TELEGRAM_BOT_TOKEN` - токен для подключения Telegram-бота
- `YOUTUBE_API_KEY` - API-ключ для доступа к YouTube Data API V3
- `POSTGRES_URL` - JDBC-строка подключения к PostgreSQL: `jdbc:postgresql://postgres:<port>/<db_name>`


### Собрать jar

Сначала нужно собрать jar файл при помощи gradle, используйте команду:
```
gradle clean build jar --no-daemon
```

### Запуск с Docker

Запустите контейнеры с помощью Docker:
```
docker-compose up --build
```

Это автоматически развернет все зависимости, включая PostgreSQL и ваше приложение.

### Запуск приложения

Проинициализируйте таблицы в Postgres. Для этого необходимо зайти в контейнер Docker. Используйте команду для получения контейнера: 

```
docker ps
```

После зайдите в окружение через команду:

```
sudo docker exec -it <conrainer_id> psql -U <user_name> -d <database_name> -W
```

Вбив пароль, выполните sql скрипты из src/main/resources/sql.

## Использование

- Найдите бота “VideoStatsAggregator” в Telegram.
- Запустите Telegram-бота:
- Отправьте ссылку на видео.
- Бот сохранит ссылку.
- Бот покажет статистику, обновит статистику и сводные данные по отслеживаемым видео, по запросу пользователя.
