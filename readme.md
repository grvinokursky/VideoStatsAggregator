
VideoStatsAggregator — это сервис для сбора и агрегации статистики просмотров видео с различных платформ. Он предоставляет удобный интерфейс через Telegram-бота для владельцев контента и аналитиков, чтобы следить за динамикой просмотров без необходимости вручную заходить на каждую платформу.

 Описание проекта
VideoStatsAggregator позволяет получать актуальную статистику по видео с платформ, таких как YouTube, VK Video и других. Система собирает данные о просмотрах и отображает статистику через Telegram-бота.
Основной функционал включает:
Получение ссылок на видео.
Определение платформы и сохранение ссылки в базе данных.
Получение и отображение статистики по просмотрам.
Поддержка нескольких платформ.
Возможность обновления статистики по кнопке.
